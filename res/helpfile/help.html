基本介绍

质谱天纲是一款基于 Python 3 + Tkinter 开发的化学桌面应用，围绕元素周期表构建了一套完整的化学学习、计算与模拟环境。当前版本为 1.3.5 Beta。

小提示： 首次启动会播放启动界面并加载 118 种元素数据。如果你的机器未安装 Unifont 字体，程序会提示安装，安装后请重启程序。

主界面一览

  • 顶部为菜单栏：菜单 / 工具 / 学科 / 插件 / 用户 / 扩展 / 其他
  • 中部为元素周期表：点击任一元素查看详细信息
  • 底部为状态栏：显示当前提示、登录状态与快捷键说明

元素周期表

主界面即完整的元素周期表，覆盖从 H 到 Og 的全部 118 种元素。

查看元素信息

点击任一元素方块，将弹出信息窗口，包含：

  • 基本信息：原子序数、原子质量、CAS 号、拉丁名、类别、电子构型、发现年份、发现者、化合价
  • 物理性质：熔点、沸点、密度、原子半径、范德华半径、布氏硬度、莫氏硬度、声速
  • 其他信息：晶体类型、体积模量、剪切模量、宇宙丰度、地壳丰度、颜色、价格、同位素
  • 元素图片（如资源包中提供）：点击可全屏显示
  • 朗读：播放该元素中文名称的音频（如资源包中提供）

浏览方式

  • 上一个 / 下一个：按原子序数顺序前后切换
  • 鼠标滚轮：在元素信息窗口中滚动切换
  • 元素检索：菜单 → 工具 → 基础化学工具 → 元素检索，可按名称/符号/原子序数快速定位
  • 图例筛选：点击底部图例按钮，只高亮所选类别的元素（其余元素变灰）
操作 效果
鼠标悬停元素状态栏显示 "符号 - 名称"
单击元素打开详细信息窗口
点击类别图例按类别筛选显示（不匹配的变灰）
主题切换主界面顶部可切换浅色 / 深色主题

化学工具

菜单 工具 下集成了大量化学计算与查阅工具，覆盖基础、分析、物理化学、有机、电化学、生物化学等多个方向。

基础化学工具

化学词典

查询化学术语与化合物解释，支持随机条目。

摩尔质量计算器

输入化学式（如 H2O、CaCO3）自动计算摩尔质量。

方程式配平器

自动配平化学方程式，支持离子方程式与变价元素。

CAS 号查询

按中文名 / 英文名 / CAS 号查询物质详细信息。

单位换算器

长度、质量、时间、温度、能量等常用单位互转。

元素比较工具

并排对比两种元素的属性差异。

分析化学工具

  • 滴定快速计算：基于 C₁V₁ = C₂V₂
  • pH 计算器：H⁺ / pH / OH⁻ / pOH 互相换算
  • 缓冲溶液计算：Henderson–Hasselbalch 方程
  • 浓度单位换算：mol/L、g/L、%、ppm 等
  • 标准溶液配制：考虑纯度与摩尔质量的称量计算
  • 化学指示剂查询：常见指示剂的变色范围
  • 不确定度分析：测量数据的统计与置信区间

物理化学工具

  • 理想气体计算器：PV = nRT
  • 反应焓变计算器：基于 Hess 定律
  • 平衡常数计算器：Kc / Kp 互算
  • 电化学计算器：能斯特方程与法拉第定律
  • 反应速率计算器：速率定律、Arrhenius 方程、半衰期
  • 热力学计算器：ΔG = ΔH − TΔS
  • 量子化学计算器：德布罗意波长、氢原子能级
  • 滴定曲线模拟：强酸强碱、弱酸强碱等多种曲线

有机化学与高级工具

  • 有机物平台：查看常见有机分子结构
  • 分子搭建器：手动搭建分子，支持 .mlcl / .json 保存
  • 3D 分子模型：旋转查看三维分子
  • 多环芳烃查看器：PAH 系列化合物一览
  • 正交试验设计：L4 / L8 / L9 / L16 等正交表及极差分析
  • Tanimoto 相似度：两种化合物的分子相似性比较
  • AI 化学助手：联网请求 HuggingFace 模型答疑
  • 化学模拟实验室：基于物理引擎的分子碰撞与反应模拟

生物化学与电化学

  • DNA / RNA 互补序列转换
  • 蛋白质分子量计算器（单字母氨基酸序列）
  • 等电点 pI 估算器
  • 缓冲液配制计算器
  • 能斯特方程计算器
  • 电解计算器（法拉第定律）

小提示： 大多数工具输入后按 Enter 即可直接计算，无需点击按钮。

可视化与模拟

菜单 工具 → 可视化与模拟 下提供多种动态演示与模拟工具。

动态原子结构图

显示元素核外电子层分布，电子绕核运动，可选择不同元素查看。

电子排布查看器

展示电子构型、能级示意图与化学性质关联。

化学实验模拟

交互式展示酸碱中和、金属与酸、沉淀、气体生成、燃烧、置换等反应现象。

电子云图像查看器

查看 s、p、d、f 各轨道的电子云 GIF。

化学学习游戏

元素记忆游戏、化学式拼写、反应配平、化学测验。

元素发现动态演示

v1.3.5 新增。拖动年份滑块，沿时间轴观察元素被逐步发现的过程；支持自动播放。

元素发现动态演示 使用方式

  1. 菜单 → 工具 → 可视化与模拟 → 元素发现动态演示
  2. 拖动底部滑块或点击「古代 / 中世纪 / 启蒙时代 / 19 世纪 / 20 世纪初 / 20 世纪中 / 现代」快速跳转
  3. 点击「▶ 播放」自动从公元前 3000 年播放到 2030 年（古代快、近代慢）
  4. 点击任一元素查看其发现年份、发现者等详细信息

用户系统

菜单 用户 下提供登录/注册、个人资料、收藏元素、局域网讨论区等功能。

登录 / 注册

  • 注册用户写入固定文件 C:/pt/user.json
  • 同时兼容旧数据文件 ./res/data/users_data.json 中的用户
  • 旧用户一旦登录或修改收藏，会自动迁移到新文件

我的收藏

登录后，在元素信息窗口点击「收藏」即可将元素加入收藏列表，从菜单 → 用户 → 我的收藏可查看。

局域网讨论区

在局域网内与其他用户实时聊天。一台机器作为主机创建讨论区，其他机器输入主机 IP 加入。

注意： 用户名不得与旧文件中已有用户名重复；密码至少 6 位；用户名至少 3 位。

常见问题

1. 启动时报"资源包版本号不匹配"怎么办？

说明 ./res/rv.prv 中的版本号与程序期望的不一致。请把该文件内容改为 36，或使用与当前程序配套的资源包。

2. 提示"Unifont 字体未安装"？

程序依赖 Unifont 字体显示全部化学符号。首次启动会尝试自动安装 ./res/fonts/unifont-17.0.05.otf，需要管理员权限。安装后请重启程序。

3. 元素图片 / 音频不显示？

这些资源存放在 ./res/images/photos/、./res/sound/name/ 等目录下。如资源包未包含这些文件，元素信息窗口会以占位符形式显示。

4. 我注册的用户保存在哪里？

新版本注册的用户保存在 C:/pt/user.json。旧版本注册的用户在 ./res/data/users_data.json 中，仍可正常登录；一旦登录或修改收藏，将自动迁移到新文件。

5. 如何自定义插件？

把 .py 文件放入 ./plugins/ 或 C:/pt/plugins/ 目录，插件管理器 → 刷新插件列表 即可识别。使用「创建插件模板」可生成示例代码。

6. 数据是否可以导出？

支持。例如：表形式查看器 可浏览 / 导出元素数据，SNO 表格 可导出 CSV，SNO 数据库 可导入 / 导出 CSV 等。

7. 这个程序可以离线使用吗？

绝大多数功能支持离线使用。仅 "AI 化学助手" 与 "官网更新" 需要联网。
