高中化学知识点及化学方程式详细整理
一、化学基本概念与理论
1. 物质分类与变化
1.1 物质分类体系
混合物：由两种或多种物质混合而成，无固定组成和性质

溶液：均一、稳定、透明的混合物，如NaCl溶液

胶体：分散质粒子直径1-100nm，具有丁达尔效应，如Fe(OH)₃胶体

浊液：分散质粒子>100nm，不稳定，如泥水

纯净物：

单质：

金属：Fe、Cu、Al等（常温下除Hg外均为固体）

非金属：C、S、P、O₂、N₂等

稀有气体：He、Ne、Ar等

化合物：

氧化物

酸性氧化物：与碱反应生成盐和水，如SO₂、CO₂、P₂O₅

碱性氧化物：与酸反应生成盐和水，如Na₂O、CaO、Fe₂O₃

两性氧化物：既与酸又与碱反应，如Al₂O₃、ZnO

不成盐氧化物：既不与酸也不与碱反应，如CO、NO

酸

按组成：含氧酸（H₂SO₄）、无氧酸（HCl）

按电离H⁺数：一元酸（HCl）、二元酸（H₂SO₄）、多元酸（H₃PO₄）

按酸性强弱：强酸、弱酸

碱

按溶解性：可溶性碱（NaOH）、难溶性碱[Cu(OH)₂]

按碱性强弱：强碱、弱碱

盐

正盐：NaCl、Na₂CO₃

酸式盐：NaHCO₃、NaHSO₄

碱式盐：Cu₂(OH)₂CO₃

复盐：KAl(SO₄)₂·12H₂O

1.2 物质变化
物理变化：无新物质生成，如蒸发、凝固、升华、凝华

化学变化：有新物质生成，伴随能量变化

基本类型：

化合反应：A + B → C

分解反应：A → B + C

置换反应：A + BC → AC + B

复分解反应：AB + CD → AD + CB（生成沉淀、气体或弱电解质）

氧化还原反应：有电子转移的反应

1.3 化学用语
化学式：

分子式：表示分子组成，如H₂O、CO₂

实验式（最简式）：原子最简整数比，如CH₂O（甲醛、乙酸、葡萄糖）

结构式：表示原子间连接顺序和方式

电子式：表示原子最外层电子排布

化学方程式书写原则：

以客观事实为基础

遵守质量守恒定律（配平）

注明反应条件（△、加热、催化剂等）

注明生成物状态（↑气体、↓沉淀）

2. 物质的量
2.1 基本概念
物质的量(n)：表示含有一定数目粒子的集体，单位：mol

阿伏伽德罗常数(N_A)：1mol任何粒子所含粒子数，N_A=6.02×10²³ mol⁻¹

摩尔质量(M)：单位物质的量的物质所具有的质量，单位g/mol，数值=相对分子质量

2.2 计算公式
n = N/N_A

n = m/M

标准状况下气体：n = V/V_m（V_m=22.4 L/mol，条件：0℃、101kPa）

溶液中：n = cV（c：mol/L，V：L）

2.3 气体定律
阿伏伽德罗定律：同温同压下，相同体积的任何气体含有相同数目的分子

理想气体状态方程：pV = nRT

R=8.314 J/(mol·K)

常用形式：pV = (m/M)RT

3. 溶液与胶体
3.1 溶液浓度表示方法
物质的量浓度：c(B) = n(B)/V，单位mol/L

质量分数：w = m(溶质)/m(溶液) × 100%

体积分数：φ = V(溶质)/V(溶液) × 100%

质量浓度：ρ(B) = m(B)/V，单位g/L

溶解度：一定温度下，100g溶剂中达到饱和时溶解的溶质质量

3.2 溶解度曲线应用
大多数固体溶解度随温度升高而增大（如KNO₃）

少数固体溶解度受温度影响不大（如NaCl）

极少数固体溶解度随温度升高而减小[如Ca(OH)₂]

气体溶解度随温度升高而减小，随压强增大而增大

3.3 胶体
制备：

Fe(OH)₃胶体：FeCl₃ + 3H₂O(沸水) → Fe(OH)₃(胶体) + 3HCl

性质：

丁达尔效应：区分胶体与溶液

电泳：胶粒带电，在电场中定向移动

聚沉：加电解质、加热、加带相反电荷胶体

提纯：渗析（半透膜）

4. 离子反应
4.1 电解质与非电解质
电解质：在水溶液或熔融状态下能导电的化合物（酸、碱、盐、水、金属氧化物）

非电解质：在上述情况下均不导电的化合物（多数有机物、非金属氧化物）

4.2 强弱电解质
强电解质：完全电离，电离用"="

强酸：HCl、H₂SO₄、HNO₃、HClO₄、HBr、HI

强碱：NaOH、KOH、Ba(OH)₂、Ca(OH)₂（微溶但完全电离）

绝大多数盐：NaCl、KNO₃等

弱电解质：部分电离，电离用"⇌"

弱酸：CH₃COOH、H₂CO₃、H₂S、HClO、HF等

弱碱：NH₃·H₂O、Fe(OH)₃、Cu(OH)₂等

水：H₂O ⇌ H⁺ + OH⁻

4.3 离子方程式书写步骤
写：写出化学方程式

拆：将易溶、易电离的物质拆成离子形式

删：删去两边相同的离子

查：检查原子守恒、电荷守恒

4.4 离子共存问题（不共存条件）
生成沉淀：Ag⁺与Cl⁻；Ba²⁺与SO₄²⁻、CO₃²⁻；Ca²⁺与CO₃²⁻等

生成气体：H⁺与CO₃²⁻、HCO₃⁻、SO₃²⁻、HSO₃⁻；OH⁻与NH₄⁺（加热）

生成弱电解质：H⁺与OH⁻、CH₃COO⁻等；OH⁻与H⁺、NH₄⁺等

发生氧化还原反应：Fe³⁺与I⁻；MnO₄⁻、ClO⁻与S²⁻、I⁻等（酸性条件下）

发生络合反应：Fe³⁺与SCN⁻

5. 氧化还原反应
5.1 基本概念
氧化：失去电子，化合价升高

还原：得到电子，化合价降低

氧化剂：得电子，化合价降低，被还原

还原剂：失电子，化合价升高，被氧化

氧化产物：还原剂被氧化后的产物

还原产物：氧化剂被还原后的产物

5.2 氧化还原反应类型
分子间氧化还原：不同物质间电子转移

分子内氧化还原：同一物质内不同元素间电子转移

歧化反应：同一物质中同种元素化合价既升又降

归中反应：同种元素不同价态反应生成中间价态

5.3 氧化性还原性强弱判断
根据反应方向：氧化性：氧化剂>氧化产物；还原性：还原剂>还原产物

根据金属活动性顺序：

金属单质还原性：K>Ca>Na>Mg>Al>Zn>Fe>Sn>Pb>(H)>Cu>Hg>Ag>Pt>Au

对应阳离子氧化性：K⁺<Ca²⁺<Na⁺<Mg²⁺<Al³⁺<Zn²⁺<Fe²⁺<Sn²⁺<Pb²⁺<(H⁺)<Cu²⁺<Hg²⁺<Ag⁺

根据非金属活动性：

非金属单质氧化性：F₂>Cl₂>Br₂>I₂>S

对应阴离子还原性：F⁻<Cl⁻<Br⁻<I⁻<S²⁻

根据反应条件：条件要求越高，反应越难进行，氧化性/还原性越弱

根据元素周期表：

同周期从左到右：金属性减弱，非金属性增强

同主族从上到下：金属性增强，非金属性减弱

5.4 氧化还原反应配平方法（以KMnO₄与HCl反应为例）
标化合价：KMnO₄ → MnCl₂，HCl → Cl₂

列变化：Mn：+7→+2，得5e⁻；Cl：-1→0，失1e⁻×2（因Cl₂中有2个Cl）

求公倍数：5和2的最小公倍数为10

配系数：2KMnO₄对应10HCl被氧化，但HCl还起酸作用，总HCl量为16

检查：原子守恒、电荷守恒

二、元素化学
1. 碱金属（第ⅠA族）
1.1 钠及其化合物
钠单质：

物理性质：银白色金属，质软，密度比水小，熔点低

化学性质活泼：

与O₂反应：

常温：4Na + O₂ → 2Na₂O（白色固体）

加热：2Na + O₂ → Na₂O₂（淡黄色固体）

与Cl₂反应：2Na + Cl₂ → 2NaCl（白烟）

与水反应：2Na + 2H₂O → 2NaOH + H₂↑（浮、熔、游、响、红）

与酸反应：2Na + 2HCl → 2NaCl + H₂↑（剧烈）

与盐溶液反应：先与水反应，生成的NaOH再与盐反应

钠的氧化物：

氧化钠（Na₂O）：碱性氧化物

Na₂O + H₂O → 2NaOH

Na₂O + CO₂ → Na₂CO₃

Na₂O + 2HCl → 2NaCl + H₂O

过氧化钠（Na₂O₂）：淡黄色固体，强氧化性

2Na₂O₂ + 2H₂O → 4NaOH + O₂↑（放热）

2Na₂O₂ + 2CO₂ → 2Na₂CO₃ + O₂（供氧剂）

Na₂O₂具有漂白性（氧化漂白）

钠的氢氧化物：NaOH（烧碱、火碱、苛性钠）

强碱，易潮解，有腐蚀性

与酸性氧化物：2NaOH + CO₂ → Na₂CO₃ + H₂O（CO₂不足）

NaOH + CO₂ → NaHCO₃（CO₂过量）

与酸中和：NaOH + HCl → NaCl + H₂O

与两性物质：2NaOH + Al₂O₃ → 2NaAlO₂ + H₂O

钠盐：

碳酸钠（Na₂CO₃，纯碱、苏打）：

稳定，水溶液碱性较强

Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑

Na₂CO₃ + Ca(OH)₂ → CaCO₃↓ + 2NaOH

与CO₂反应：Na₂CO₃ + H₂O + CO₂ → 2NaHCO₃

碳酸氢钠（NaHCO₃，小苏打）：

不稳定，受热分解：2NaHCO₃ → Na₂CO₃ + H₂O + CO₂↑

水溶液碱性较弱

NaHCO₃ + HCl → NaCl + H₂O + CO₂↑

与碱反应：NaHCO₃ + NaOH → Na₂CO₃ + H₂O

鉴别Na₂CO₃和NaHCO₃：

加热：产生气体的是NaHCO₃

加酸：反应更剧烈的是NaHCO₃

加CaCl₂：产生沉淀的是Na₂CO₃

1.2 钾及其化合物
性质与钠相似，但更活泼

钾的焰色反应：紫色（透过蓝色钴玻璃观察）

钠的焰色反应：黄色

2. 卤素（第ⅦA族）
2.1 氯及其化合物
氯气（Cl₂）：

物理性质：黄绿色气体，有刺激性气味，有毒，密度比空气大，能溶于水

化学性质：

与金属反应：

2Na + Cl₂ → 2NaCl（白烟）

2Fe + 3Cl₂ → 2FeCl₃（棕褐色烟）

Cu + Cl₂ → CuCl₂（棕黄色烟）

与非金属反应：

H₂ + Cl₂ → 2HCl（苍白色火焰，光照爆炸）

2P + 3Cl₂ → 2PCl₃（液），PCl₃ + Cl₂ → PCl₅（固）

与水反应：Cl₂ + H₂O ⇌ HCl + HClO（可逆反应）

HClO：弱酸，不稳定，见光分解：2HClO → 2HCl + O₂↑

HClO有强氧化性（漂白、杀菌消毒）

与碱反应：

Cl₂ + 2NaOH → NaCl + NaClO + H₂O（制漂白液）

2Cl₂ + 2Ca(OH)₂ → CaCl₂ + Ca(ClO)₂ + 2H₂O（制漂白粉）

与还原性物质反应：

Cl₂ + 2KI → 2KCl + I₂（淀粉变蓝，检验Cl₂）

Cl₂ + H₂S → 2HCl + S↓

Cl₂ + SO₂ + 2H₂O → H₂SO₄ + 2HCl

氯的含氧酸：

次氯酸（HClO）：弱酸，仅存在于溶液中，强氧化性

氯酸（HClO₃）：强酸，强氧化性

高氯酸（HClO₄）：最强无机酸，氧化性较弱

氯离子（Cl⁻）检验：

取样→加稀HNO₃酸化→加AgNO₃溶液→白色沉淀（AgCl）

2.2 溴、碘及其化合物
溴（Br₂）：深红棕色液体，易挥发，有毒

碘（I₂）：紫黑色固体，易升华，遇淀粉变蓝

溴化银（AgBr）：淡黄色沉淀，见光分解（照相底片）

碘化银（AgI）：黄色沉淀，人工降雨

2.3 卤素性质递变规律
单质颜色加深：F₂（淡黄绿）→Cl₂（黄绿）→Br₂（红棕）→I₂（紫黑）

状态变化：气→液→固

熔沸点升高

氧化性：F₂>Cl₂>Br₂>I₂

还原性：F⁻<Cl⁻<Br⁻<I⁻

3. 氧族元素（第ⅥA族）
3.1 氧和臭氧
氧气（O₂）：无色无味气体，助燃

2H₂ + O₂ → 2H₂O

C + O₂ → CO₂

3Fe + 2O₂ → Fe₃O₄

臭氧（O₃）：淡蓝色气体，有鱼腥味，强氧化性

2O₃ ⇌ 3O₂（可逆）

用于消毒、漂白

3.2 硫及其化合物
硫单质（S）：

物理性质：黄色固体，不溶于水，微溶于酒精，易溶于CS₂

化学性质：

与金属反应：Fe + S → FeS；2Cu + S → Cu₂S

与非金属反应：S + O₂ → SO₂；S + H₂ → H₂S

与碱反应：3S + 6NaOH → 2Na₂S + Na₂SO₃ + 3H₂O（歧化）

硫化氢（H₂S）：

无色有臭鸡蛋味气体，有毒，可燃

2H₂S + 3O₂（足量）→ 2SO₂ + 2H₂O

2H₂S + O₂（不足）→ 2S↓ + 2H₂O

H₂S + CuSO₄ → CuS↓（黑色）+ H₂SO₄

二氧化硫（SO₂）：

无色有刺激性气味气体，有毒，易液化，易溶于水

化学性质：

酸性氧化物通性：

SO₂ + H₂O ⇌ H₂SO₃（可逆）

SO₂ + 2NaOH → Na₂SO₃ + H₂O

SO₂ + Ca(OH)₂ → CaSO₃↓ + H₂O（使石灰水变浑浊，与CO₂相似）

还原性：

2SO₂ + O₂ ⇌ 2SO₃（催化剂，可逆）

SO₂ + Cl₂ + 2H₂O → H₂SO₄ + 2HCl

SO₂ + 2H₂S → 3S↓ + 2H₂O

5SO₂ + 2KMnO₄ + 2H₂O → K₂SO₄ + 2MnSO₄ + 2H₂SO₄（褪色）

氧化性：SO₂ + 2H₂S → 3S↓ + 2H₂O

漂白性：与有色物质结合生成不稳定的无色化合物（可逆，加热复原）

三氧化硫（SO₃）：

无色固体，易挥发，强氧化性

SO₃ + H₂O → H₂SO₄（放热剧烈）

SO₃ + CaO → CaSO₄

硫酸（H₂SO₄）：

浓硫酸特性：

吸水性：作干燥剂（不能干燥NH₃、H₂S、HI等）

脱水性：将有机物中H、O按2:1脱去

C₁₂H₂₂O₁₁（蔗糖）→ 12C + 11H₂O

强氧化性：

与金属反应（常温下使Fe、Al钝化）：

Cu + 2H₂SO₄(浓) → CuSO₄ + SO₂↑ + 2H₂O

C + 2H₂SO₄(浓) → CO₂↑ + 2SO₂↑ + 2H₂O

与非金属反应：

C + 2H₂SO₄(浓) → CO₂↑ + 2SO₂↑ + 2H₂O

S + 2H₂SO₄(浓) → 3SO₂↑ + 2H₂O

稀硫酸：具有酸的通性

硫酸根检验（SO₄²⁻）：

取样→加稀HCl酸化→加BaCl₂溶液→白色沉淀（BaSO₄）

3.3 硫酸工业
接触法制硫酸：

硫铁矿焙烧：4FeS₂ + 11O₂ → 2Fe₂O₃ + 8SO₂

SO₂催化氧化：2SO₂ + O₂ ⇌ 2SO₃（V₂O₅催化，400-500℃）

SO₃吸收：SO₃ + H₂O → H₂SO₄（用98.3%浓H₂SO₄吸收）

4. 氮族元素（第ⅤA族）
4.1 氮及其化合物
氮气（N₂）：

无色无味气体，化学性质稳定

N₂ + 3H₂ ⇌ 2NH₃（高温高压催化剂）

N₂ + O₂ → 2NO（放电条件）

氨（NH₃）：

无色有刺激性气味气体，极易溶于水（1:700），易液化

化学性质：

与水反应：NH₃ + H₂O ⇌ NH₃·H₂O ⇌ NH₄⁺ + OH⁻（弱碱性）

与酸反应：NH₃ + HCl → NH₄Cl（白烟）

还原性：

4NH₃ + 5O₂ → 4NO + 6H₂O（催化氧化，制硝酸）

8NH₃ + 3Cl₂ → N₂ + 6NH₄Cl（检验氯气管道泄漏）

络合反应：Ag⁺ + 2NH₃ → [Ag(NH₃)₂]⁺（银氨溶液）

氨水：NH₃的水溶液，易挥发，弱碱性

铵盐：易溶于水，受热分解，与碱反应

NH₄Cl → NH₃↑ + HCl↑（遇冷又化合）

NH₄HCO₃ → NH₃↑ + H₂O + CO₂↑

2NH₄Cl + Ca(OH)₂ → CaCl₂ + 2H₂O + 2NH₃↑（实验室制NH₃）

氮的氧化物：

NO：无色气体，不溶于水，易与O₂反应：2NO + O₂ → 2NO₂

NO₂：红棕色气体，有刺激性气味，有毒

3NO₂ + H₂O → 2HNO₃ + NO（工业制硝酸）

2NO₂ ⇌ N₂O₄（可逆，存在平衡）

硝酸（HNO₃）：

纯硝酸无色，易挥发，有刺激性气味，遇光分解：4HNO₃ → 4NO₂↑ + O₂↑ + 2H₂O（棕色瓶避光保存）

化学性质：

强酸性：具有酸的通性

强氧化性：

与金属反应（除Au、Pt外）：

Cu + 4HNO₃(浓) → Cu(NO₃)₂ + 2NO₂↑ + 2H₂O

3Cu + 8HNO₃(稀) → 3Cu(NO₃)₂ + 2NO↑ + 4H₂O

常温下浓HNO₃使Fe、Al钝化

与非金属反应：

C + 4HNO₃(浓) → CO₂↑ + 4NO₂↑ + 2H₂O

S + 6HNO₃(浓) → H₂SO₄ + 6NO₂↑ + 2H₂O

与还原性化合物反应：

3Fe²⁺ + 4H⁺ + NO₃⁻ → 3Fe³⁺ + NO↑ + 2H₂O

酯化反应：与醇生成硝酸酯

硝酸工业制法：

氨的催化氧化：4NH₃ + 5O₂ → 4NO + 6H₂O（Pt-Rh催化）

NO氧化：2NO + O₂ → 2NO₂

NO₂吸收：3NO₂ + H₂O → 2HNO₃ + NO（循环利用）

4.2 磷及其化合物
白磷：蜡状固体，剧毒，着火点40℃，保存在水中

红磷：红棕色粉末，无毒，着火点240℃，密封保存

相互转化：白磷 ⇌ 红磷（隔绝空气加热）

磷燃烧：4P + 5O₂ → 2P₂O₅（白烟，P₂O₅是常用干燥剂）

磷酸（H₃PO₄）：中强酸，三元酸，无氧化性，可形成三种盐

5. 碳族元素（第ⅣA族）
5.1 碳及其化合物
碳单质：

金刚石：原子晶体，硬度最大，不导电

石墨：混合晶体，质软，导电

C₆₀：分子晶体，足球烯

化学性质：

可燃性：C + O₂ → CO₂（足量O₂）；2C + O₂ → 2CO（不足O₂）

还原性：C + 2CuO → 2Cu + CO₂↑；C + CO₂ → 2CO（吸热）

与水蒸气：C + H₂O(g) → CO + H₂（水煤气）

一氧化碳（CO）：

无色无味气体，有毒（与血红蛋白结合）

可燃性：2CO + O₂ → 2CO₂（蓝色火焰）

还原性：CO + CuO → Cu + CO₂；3CO + Fe₂O₃ → 2Fe + 3CO₂

二氧化碳（CO₂）：

无色无味气体，密度比空气大，能溶于水

酸性氧化物通性：

CO₂ + H₂O ⇌ H₂CO₃

CO₂ + 2NaOH → Na₂CO₃ + H₂O（不足）

CO₂ + NaOH → NaHCO₃（过量）

弱氧化性：CO₂ + C → 2CO；CO₂ + 2Mg → 2MgO + C（耀眼白光）

制取：CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑

检验：通入澄清石灰水变浑浊，再通入变澄清

碳酸盐：

溶解性：Na、K、NH₄⁺的碳酸盐易溶，其余难溶

热稳定性：碱金属碳酸盐>碱土金属碳酸盐>过渡金属碳酸盐

相互转化：Na₂CO₃ ⇌ NaHCO₃（通CO₂或加NaOH）

碳酸根检验：加酸产生使石灰水变浑浊的气体

5.2 硅及其化合物
硅单质：

晶体硅：灰黑色，有金属光泽，半导体

化学性质不活泼：

Si + 2F₂ → SiF₄

Si + 2NaOH + H₂O → Na₂SiO₃ + 2H₂↑（唯一与碱反应的金属）

Si + O₂ → SiO₂（高温）

二氧化硅（SiO₂）：

原子晶体，坚硬，熔点高，不溶于水

酸性氧化物，但只与HF反应：SiO₂ + 4HF → SiF₄↑ + 2H₂O（刻蚀玻璃）

与碱反应：SiO₂ + 2NaOH → Na₂SiO₃ + H₂O

与碱性氧化物反应：SiO₂ + CaO → CaSiO₃（炼铁造渣）

硅酸（H₂SiO₃）：

白色胶状沉淀，弱酸，不溶于水

制取：Na₂SiO₃ + 2HCl → H₂SiO₃↓ + 2NaCl

脱水生成硅胶：H₂SiO₃ → SiO₂ + H₂O（干燥剂）

硅酸盐：

硅酸钠（Na₂SiO₃）：水玻璃，粘合剂，防火材料

普通玻璃成分：Na₂SiO₃·CaSiO₃·4SiO₂

水泥主要成分：3CaO·SiO₂、2CaO·SiO₂、3CaO·Al₂O₃

6. 金属元素
6.1 铝及其化合物
铝单质：

银白色轻金属，导电导热性好

化学性质：

与O₂反应：4Al + 3O₂ → 2Al₂O₃（致密氧化膜，抗腐蚀）

与酸反应：2Al + 6HCl → 2AlCl₃ + 3H₂↑

与碱反应：2Al + 2NaOH + 6H₂O → 2Na[Al(OH)₄] + 3H₂↑（四羟基合铝酸钠）

铝热反应：2Al + Fe₂O₃ → 2Fe + Al₂O₃（高温）

氧化铝（Al₂O₃）：

白色固体，难溶于水，熔点高

两性氧化物：

Al₂O₃ + 6HCl → 2AlCl₃ + 3H₂O

Al₂O₃ + 2NaOH + 3H₂O → 2Na[Al(OH)₄]

氢氧化铝[Al(OH)₃]：

白色胶状沉淀，两性氢氧化物

Al(OH)₃ + 3HCl → AlCl₃ + 3H₂O

Al(OH)₃ + NaOH → Na[Al(OH)₄]

不稳定性：2Al(OH)₃ → Al₂O₃ + 3H₂O（加热）

制取：Al³⁺ + 3NH₃·H₂O → Al(OH)₃↓ + 3NH₄⁺（氨水）

铝盐：

硫酸铝钾[KAl(SO₄)₂·12H₂O]：明矾，净水剂

Al³⁺水解：Al³⁺ + 3H₂O ⇌ Al(OH)₃（胶体）+ 3H⁺

6.2 铁及其化合物
铁单质：

物理性质：银白色金属，延展性、导电导热性好

化学性质：

与非金属反应：

3Fe + 2O₂ → Fe₃O₄

2Fe + 3Cl₂ → 2FeCl₃

Fe + S → FeS

与水反应：3Fe + 4H₂O(g) → Fe₃O₄ + 4H₂（高温）

与酸反应：

与非氧化性酸：Fe + 2H⁺ → Fe²⁺ + H₂↑

与氧化性酸（浓H₂SO₄、浓HNO₃）：常温钝化

与稀HNO₃：Fe + 4HNO₃(稀) → Fe(NO₃)₃ + NO↑ + 2H₂O（过量）

与盐溶液反应：Fe + Cu²⁺ → Fe²⁺ + Cu

铁的氧化物：

FeO：黑色，碱性氧化物，不稳定

Fe₂O₃：红棕色，碱性氧化物（铁红）

Fe₃O₄：黑色，具有磁性，可视为FeO·Fe₂O₃

铁的氢氧化物：

Fe(OH)₂：白色沉淀，不稳定

4Fe(OH)₂ + O₂ + 2H₂O → 4Fe(OH)₃（白色→灰绿→红褐）

Fe(OH)₃：红褐色沉淀

2Fe(OH)₃ → Fe₂O₃ + 3H₂O（加热）

铁盐：

Fe²⁺：浅绿色，还原性

2Fe²⁺ + Cl₂ → 2Fe³⁺ + 2Cl⁻

5Fe²⁺ + MnO₄⁻ + 8H⁺ → 5Fe³⁺ + Mn²⁺ + 4H₂O

Fe³⁺：黄色，氧化性

2Fe³⁺ + Fe → 3Fe²⁺

2Fe³⁺ + Cu → 2Fe²⁺ + Cu²⁺

Fe³⁺ + 3SCN⁻ ⇌ Fe(SCN)₃（血红色，检验Fe³⁺）

Fe²⁺与Fe³⁺相互转化：

Fe²⁺ → Fe³⁺：加氧化剂（Cl₂、HNO₃、KMnO₄等）

Fe³⁺ → Fe²⁺：加还原剂（Fe、Cu、I⁻等）

铁离子检验：

Fe³⁺：加KSCN溶液，血红色；加NaOH，红褐色沉淀

Fe²⁺：加NaOH，白色沉淀→灰绿→红褐；加KSCN无现象，再加氯水变红

6.3 铜及其化合物
铜单质：

紫红色金属，导电导热性好

化学性质：

2Cu + O₂ → 2CuO（黑色）；2Cu + O₂ + CO₂ + H₂O → Cu₂(OH)₂CO₃（铜绿）

Cu + Cl₂ → CuCl₂（棕黄色烟）

Cu + 2H₂SO₄(浓) → CuSO₄ + SO₂↑ + 2H₂O

Cu + 4HNO₃(浓) → Cu(NO₃)₂ + 2NO₂↑ + 2H₂O

铜的化合物：

氧化铜（CuO）：黑色，碱性氧化物

氧化亚铜（Cu₂O）：红色

硫酸铜（CuSO₄）：白色，吸水变蓝（检验水）

五水硫酸铜（CuSO₄·5H₂O）：蓝色晶体

氢氧化铜[Cu(OH)₂]：蓝色沉淀

Cu(OH)₂ + 2HCl → CuCl₂ + 2H₂O

Cu(OH)₂ + 4NH₃ → Cu(NH₃)₄₂（深蓝色溶液）

三、化学反应原理
1. 化学反应速率与化学平衡
1.1 化学反应速率
定义：单位时间内反应物浓度的减少或生成物浓度的增加

表达式：v = Δc/Δt，单位：mol/(L·s)或mol/(L·min)

同一反应中，各物质速率比等于化学计量数比

影响因素：

浓度：增大反应物浓度，v增大

压强（气体反应）：增大压强，v增大（实质是增大浓度）

温度：升高温度，v增大（一般每升高10℃，v增大2-4倍）

催化剂：改变化学反应速率

其他：固体表面积、光、射线、溶剂等

1.2 化学平衡
可逆反应：在同一条件下既能向正方向又能向逆方向进行的反应

化学平衡状态特征：逆、等、动、定、变

逆：可逆反应

等：v(正)=v(逆)≠0

动：动态平衡

定：各组分浓度、百分含量保持不变

变：条件改变，平衡可能移动

平衡常数K：

对于反应：aA + bB ⇌ cC + dD，K = [C]^c[D]^d/([A]^a[B]^b)

K只与温度有关，与浓度、压强、催化剂无关

K>10⁵：反应完全；K<10⁻⁵：反应很难进行

1.3 平衡移动原理（勒夏特列原理）
内容：如果改变影响平衡的一个条件，平衡就向能够减弱这种改变的方向移动

影响因素：

浓度：增加反应物浓度或减少生成物浓度，平衡正向移动

压强（气体反应）：

增大压强，平衡向气体体积减小的方向移动

减小压强，平衡向气体体积增大的方向移动

反应前后气体体积不变，压强改变不影响平衡

温度：

升高温度，平衡向吸热方向移动

降低温度，平衡向放热方向移动

催化剂：同等程度改变正逆反应速率，平衡不移动，但缩短达到平衡的时间

2. 电解质溶液
2.1 水的电离与溶液pH
水的电离：H₂O ⇌ H⁺ + OH⁻，25℃时K_w = [H⁺][OH⁻] = 1.0×10⁻¹⁴

pH定义：pH = -lg[H⁺]，pOH = -lg[OH⁻]，pH + pOH = 14（25℃）

溶液酸碱性与pH：

酸性：[H⁺]>[OH⁻]，pH<7

中性：[H⁺]=[OH⁻]，pH=7

碱性：[H⁺]<[OH⁻]，pH>7

pH计算：

强酸：pH = -lgc(酸)

强碱：先求pOH = -lgc(碱)，再求pH = 14-pOH

弱酸、弱碱：考虑电离度

混合溶液：近似计算或精确计算

2.2 盐类水解
定义：盐电离出的离子与水电离出的H⁺或OH⁻结合生成弱电解质的反应

规律：有弱才水解，无弱不水解，谁弱谁水解，谁强显谁性

强酸弱碱盐：水解显酸性，如NH₄Cl、CuSO₄

强碱弱酸盐：水解显碱性，如Na₂CO₃、CH₃COONa

弱酸弱碱盐：双水解，酸碱性取决于K_a与K_b相对大小

强酸强碱盐：不水解，显中性，如NaCl、KNO₃

影响水解因素：

温度：升高温度，促进水解

浓度：稀释促进水解

外加酸碱：抑制或促进水解

水解应用：泡沫灭火器、净水、化肥施用、盐类制备

2.3 沉淀溶解平衡
溶度积常数K_sp：对于A_mB_n(s) ⇌ mAⁿ⁺(aq) + nBᵐ⁻(aq)，K_sp = [Aⁿ⁺]^m[Bᵐ⁻]^n

溶度积规则：

Q_c > K_sp：有沉淀生成

Q_c = K_sp：饱和溶液，平衡状态

Q_c < K_sp：不饱和溶液，无沉淀或沉淀溶解

沉淀转化：向更难溶物质转化

应用：锅炉除垢、矿物转化、沉淀分离

3. 电化学基础
3.1 原电池
工作原理：化学能→电能

构成条件：

活泼性不同的两个电极

电解质溶液

闭合回路

自发氧化还原反应

电极名称：

负极：电子流出，发生氧化反应

正极：电子流入，发生还原反应

常见原电池：

铜锌原电池：

负极(Zn)：Zn - 2e⁻ → Zn²⁺

正极(Cu)：2H⁺ + 2e⁻ → H₂↑

干电池：锌锰电池

铅蓄电池：可充电

氢氧燃料电池：

负极：2H₂ - 4e⁻ + 4OH⁻ → 4H₂O

正极：O₂ + 4e⁻ + 2H₂O → 4OH⁻

3.2 电解池
工作原理：电能→化学能

构成条件：

直流电源

两个电极

电解质溶液或熔融电解质

电极名称：

阳极：与电源正极相连，发生氧化反应

阴极：与电源负极相连，发生还原反应

放电顺序：

阳极：活泼金属>S²⁻>I⁻>Br⁻>Cl⁻>OH⁻>含氧酸根

阴极：Ag⁺>Fe³⁺>Cu²⁺>H⁺(酸)>Fe²⁺>Zn²⁺>H⁺(水)>Al³⁺>Mg²⁺>Na⁺

应用：

氯碱工业：电解饱和食盐水

阳极：2Cl⁻ - 2e⁻ → Cl₂↑

阴极：2H₂O + 2e⁻ → H₂↑ + 2OH⁻

总反应：2NaCl + 2H₂O → 2NaOH + H₂↑ + Cl₂↑

电镀：镀件作阴极，镀层金属作阳极，含镀层金属离子的溶液作电解液

电解精炼：粗铜作阳极，精铜作阴极，CuSO₄溶液作电解液

电冶金：电解熔融Al₂O₃制Al，电解熔融NaCl制Na

3.3 金属腐蚀与防护
化学腐蚀：金属与接触到的物质直接反应

电化学腐蚀（更普遍）：

析氢腐蚀（酸性环境）：Fe - 2e⁻ → Fe²⁺；2H⁺ + 2e⁻ → H₂↑

吸氧腐蚀（中性、碱性环境）：2Fe - 4e⁻ → 2Fe²⁺；O₂ + 2H₂O + 4e⁻ → 4OH⁻

防护方法：

改变金属内部结构（合金）

覆盖保护层（涂油、刷漆、电镀）

电化学保护（牺牲阳极、外加电流）

4. 化学反应的热效应
4.1 反应热
焓变(ΔH)：恒压条件下的反应热

吸热反应：ΔH>0，如Ba(OH)₂·8H₂O与NH₄Cl反应，大多数分解反应

放热反应：ΔH<0，如燃烧、中和、金属与酸、大多数化合反应

4.2 热化学方程式
注明物质状态：s、l、g、aq

注明反应条件：温度、压强（若不注明则指25℃、101kPa）

ΔH单位：kJ/mol，与化学计量数对应

示例：C(s) + O₂(g) → CO₂(g) ΔH = -393.5 kJ/mol

4.3 燃烧热与中和热
燃烧热：1mol纯物质完全燃烧生成稳定氧化物时放出的热量

C→CO₂(g)，H→H₂O(l)，S→SO₂(g)

中和热：在稀溶液中，强酸与强碱生成1mol H₂O时的反应热

ΔH = -57.3 kJ/mol（与酸碱种类无关）

4.4 盖斯定律
内容：化学反应的反应热只与反应的始态和终态有关，与途径无关

应用：通过已知反应热计算未知反应热

四、有机化学基础
1. 有机化学基本概念
1.1 有机物特点
种类繁多

熔沸点较低

难溶于水，易溶于有机溶剂

反应慢且复杂，常伴有副反应

多数易燃

1.2 有机物的分类
按碳架分类：

链状化合物：如CH₃CH₂CH₃

环状化合物

脂环化合物：如环己烷

芳香化合物：含苯环，如苯

按官能团分类：

烷烃：C-C单键

烯烃：C=C双键

炔烃：C≡C三键

芳香烃：苯环

卤代烃：-X

醇：-OH（羟基）

酚：-OH直接连在苯环上

醚：C-O-C

醛：-CHO

酮：C=O（羰基）

羧酸：-COOH

酯：-COOR

胺：-NH₂

酰胺：-CONH₂

1.3 同分异构现象
构造异构：

碳链异构：如正丁烷与异丁烷

位置异构：如1-丁烯与2-丁烯

官能团异构：如乙醇与甲醚

立体异构：

顺反异构：如顺-2-丁烯与反-2-丁烯

对映异构（手性异构）：如乳酸

2. 烃类
2.1 烷烃（通式：C_nH_{2n+2}）
代表物：甲烷(CH₄)

结构：正四面体，sp³杂化，键角109°28′

化学性质：

取代反应（光照条件）：

CH₄ + Cl₂ → CH₃Cl + HCl（一氯代）

继续取代生成CH₂Cl₂、CHCl₃、CCl₄

氧化反应：

CH₄ + 2O₂ → CO₂ + 2H₂O（淡蓝色火焰）

热分解：CH₄ → C + 2H₂（高温）

2.2 烯烃（通式：C_nH_{2n}，n≥2）
代表物：乙烯(C₂H₄)

结构：平面结构，sp²杂化，键角120°

化学性质：

加成反应：

加H₂：CH₂=CH₂ + H₂ → CH₃CH₃（催化剂，加热）

加X₂：CH₂=CH₂ + Br₂ → CH₂BrCH₂Br（使溴水褪色）

加HX：CH₂=CH₂ + HCl → CH₃CH₂Cl（马氏规则）

加水：CH₂=CH₂ + H₂O → CH₃CH₂OH（催化剂，加热加压）

氧化反应：

燃烧：C₂H₄ + 3O₂ → 2CO₂ + 2H₂O（火焰明亮有黑烟）

被KMnO₄氧化：使酸性KMnO₄褪色（检验不饱和键）

加聚反应：nCH₂=CH₂ → [CH₂-CH₂]_n（聚乙烯）

2.3 炔烃（通式：C_nH_{2n-2}，n≥2）
代表物：乙炔(C₂H₂)

结构：直线形，sp杂化，键角180°

实验室制法：CaC₂ + 2H₂O → Ca(OH)₂ + C₂H₂↑

化学性质：

加成反应：

加H₂：C₂H₂ + 2H₂ → C₂H₆（催化剂）

加Br₂：C₂H₂ + 2Br₂ → CHBr₂CHBr₂（使溴水褪色）

加HCl：C₂H₂ + HCl → CH₂=CHCl，继续加成→CH₃CHCl₂

氧化反应：

燃烧：2C₂H₂ + 5O₂ → 4CO₂ + 2H₂O（火焰明亮，浓烟）

加成聚合：

制聚氯乙烯：nCH₂=CHCl → [CH₂-CHCl]_n

金属炔化物生成：

HC≡CH + 2Ag(NH₃)₂⁺ → AgC≡CAg↓ + 2NH₄⁺ + 2NH₃（白色沉淀）

2.4 芳香烃
苯(C₆H₆)：

结构：平面正六边形，键角120°，介于单双键之间的特殊键

化学性质：

取代反应：

卤代：C₆H₆ + Br₂ → C₆H₅Br + HBr（FeBr₃催化）

硝化：C₆H₆ + HNO₃ → C₆H₅NO₂ + H₂O（浓H₂SO₄，50-60℃）

磺化：C₆H₆ + H₂SO₄ → C₆H₅SO₃H + H₂O（70-80℃）

烷基化：C₆H₆ + CH₃Cl → C₆H₅CH₃ + HCl（AlCl₃催化）

加成反应：

加H₂：C₆H₆ + 3H₂ → C₆H₁₂（环己烷，催化剂，加热）

氧化反应：苯不能被KMnO₄氧化，但苯的同系物侧链可被氧化

甲苯(C₆H₅CH₃)：

硝化：生成TNT（三硝基甲苯）

C₆H₅CH₃ + 3HNO₃ → C₆H₂(NO₂)₃CH₃ + 3H₂O（浓H₂SO₄）

氧化：侧链被酸性KMnO₄氧化为羧基

5C₆H₅CH₃ + 6KMnO₄ + 9H₂SO₄ → 5C₆H₅COOH + 3K₂SO₄ + 6MnSO₄ + 14H₂O

3. 烃的衍生物
3.1 卤代烃（R-X）
代表物：溴乙烷(CH₃CH₂Br)

化学性质：

取代反应（水解）：

CH₃CH₂Br + NaOH → CH₃CH₂OH + NaBr（水溶液中）

消去反应：

CH₃CH₂Br + NaOH → CH₂=CH₂↑ + NaBr + H₂O（醇溶液中，加热）

与金属反应：

2CH₃CH₂Br + 2Na → CH₃CH₂CH₂CH₃ + 2NaBr（Wurtz反应）

3.2 醇（R-OH）
乙醇(CH₃CH₂OH)：

化学性质：

与活泼金属反应：2CH₃CH₂OH + 2Na → 2CH₃CH₂ONa + H₂↑

氧化反应：

燃烧：CH₃CH₂OH + 3O₂ → 2CO₂ + 3H₂O

催化氧化：2CH₃CH₂OH + O₂ → 2CH₃CHO + 2H₂O（Cu或Ag催化，加热）

被酸性KMnO₄或K₂Cr₂O₇氧化：直接氧化为乙酸

酯化反应：CH₃COOH + CH₃CH₂OH ⇌ CH₃COOCH₂CH₃ + H₂O（浓H₂SO₄催化，可逆）

脱水反应：

分子内脱水：CH₃CH₂OH → CH₂=CH₂↑ + H₂O（浓H₂SO₄，170℃）

分子间脱水：2CH₃CH₂OH → CH₃CH₂OCH₂CH₃ + H₂O（浓H₂SO₄，140℃）

甲醇(CH₃OH)：有毒，工业酒精中常添加甲醇防止饮用

多元醇：

乙二醇：HOCH₂CH₂OH，防冻液

丙三醇（甘油）：HOCH₂CH(OH)CH₂OH，制硝化甘油

3.3 酚
苯酚(C₆H₅OH)：

物理性质：无色晶体，有特殊气味，易被氧化而显粉红色

化学性质：

弱酸性：C₆H₅OH ⇌ C₆H₅O⁻ + H⁺（酸性弱于H₂CO₃）

C₆H₅OH + NaOH → C₆H₅ONa + H₂O

C₆H₅ONa + CO₂ + H₂O → C₆H₅OH + NaHCO₃（不生成Na₂CO₃）

取代反应：苯酚与浓溴水反应生成三溴苯酚白色沉淀

C₆H₅OH + 3Br₂ → C₆H₂Br₃OH↓ + 3HBr（灵敏检验反应）

显色反应：遇FeCl₃溶液显紫色

氧化反应：易被氧化，空气中变粉红色

缩聚反应：制酚醛树脂

3.4 醛和酮
乙醛(CH₃CHO)：

化学性质：

加成反应（还原反应）：CH₃CHO + H₂ → CH₃CH₂OH（催化剂，加热）

氧化反应：

银镜反应：CH₃CHO + 2Ag(NH₃)₂OH → CH₃COONH₄ + 2Ag↓ + 3NH₃ + H₂O（水浴加热）

与新制Cu(OH)₂反应：CH₃CHO + 2Cu(OH)₂ + NaOH → CH₃COONa + Cu₂O↓ + 3H₂O（加热）

被氧气氧化：2CH₃CHO + O₂ → 2CH₃COOH（催化剂）

聚合反应：nCH₃CHO → (CH₃CHO)_n（三聚乙醛）

甲醛(HCHO)：

性质与乙醛相似，但有两个醛基

与苯酚缩聚制酚醛树脂

3.5 羧酸
乙酸(CH₃COOH)：

化学性质：

酸性：CH₃COOH ⇌ CH₃COO⁻ + H⁺（弱酸）

使石蕊变红，与碱、金属氧化物、金属、某些盐反应

酯化反应：CH₃COOH + C₂H₅OH ⇌ CH₃COOC₂H₅ + H₂O（浓H₂SO₄，加热）

α-H取代：CH₃COOH + Cl₂ → ClCH₂COOH + HCl（红磷催化）

甲酸(HCOOH)：既有羧基又有醛基，能发生银镜反应

高级脂肪酸：

硬脂酸(C₁₇H₃₅COOH)：饱和脂肪酸

油酸(C₁₇H₃₃COOH)：不饱和脂肪酸，含一个C=C

3.6 酯
乙酸乙酯(CH₃COOC₂H₅)：

物理性质：无色有果香味液体，难溶于水

化学性质：水解反应（可逆）

酸性水解：CH₃COOC₂H₅ + H₂O ⇌ CH₃COOH + C₂H₅OH（稀H₂SO₄催化）

碱性水解：CH₃COOC₂H₅ + NaOH → CH₃COONa + C₂H₅OH（完全水解）

4. 生命物质
4.1 糖类
单糖：

葡萄糖(C₆H₁₂O₆)：多羟基醛，能发生银镜反应，还原性糖

发酵：C₆H₁₂O₆ → 2C₂H₅OH + 2CO₂（酒化酶）

果糖：多羟基酮，与葡萄糖互为同分异构体

二糖：

蔗糖(C₁₂H₂₂O₁₁)：非还原性糖，水解生成葡萄糖和果糖

麦芽糖(C₁₂H₂₂O₁₁)：还原性糖，水解生成两分子葡萄糖

多糖：

淀粉[(C₆H₁₀O₅)_n]：遇碘变蓝，水解最终生成葡萄糖

纤维素[(C₆H₁₀O₅)_n]：每个葡萄糖单元有三个羟基，可酯化

4.2 蛋白质
氨基酸：两性化合物，既能与酸又能与碱反应

通式：H₂N-CHR-COOH

等电点：氨基酸以两性离子形式存在时的pH

蛋白质性质：

两性：含有-NH₂和-COOH

水解：最终生成氨基酸

盐析：加浓无机盐使蛋白质沉淀（可逆）

变性：加热、紫外线、重金属盐、强酸碱、有机物使蛋白质变性（不可逆）

颜色反应：

遇浓HNO₃变黄（苯环硝化）

双缩脲反应：遇CuSO₄碱性溶液显紫色

灼烧：有烧焦羽毛气味（鉴别蛋白质）

4.3 油脂
成分：高级脂肪酸甘油酯

分类：

油：不饱和高级脂肪酸甘油酯，常温液态

脂肪：饱和高级脂肪酸甘油酯，常温固态

化学性质：

水解（皂化反应）：

(C₁₇H₃₅COO)₃C₃H₅ + 3NaOH → 3C₁₇H₃₅COONa + C₃H₅(OH)₃

氢化（硬化）：

不饱和油脂加H₂变为饱和脂肪（制人造奶油）

酸败：油脂氧化变质

5. 合成高分子
5.1 加聚反应
聚乙烯：nCH₂=CH₂ → [CH₂-CH₂]_n

聚氯乙烯：nCH₂=CHCl → [CH₂-CHCl]_n

聚苯乙烯：nC₆H₅CH=CH₂ → [CH₂-CH(C₆H₅)]_n

聚丙烯：nCH₂=CHCH₃ → [CH₂-CH(CH₃)]_n

聚四氟乙烯：nCF₂=CF₂ → [CF₂-CF₂]_n

聚甲基丙烯酸甲酯（有机玻璃）：nCH₂=C(CH₃)COOCH₃ → [CH₂-C(CH₃)(COOCH₃)]_n

5.2 缩聚反应
聚酯：

涤纶：对苯二甲酸与乙二醇缩聚

聚酰胺：

尼龙-66：己二酸与己二胺缩聚

蛋白质：氨基酸缩聚

酚醛树脂：苯酚与甲醛缩聚

6. 有机推断与合成
6.1 官能团特征反应
碳碳双键：使溴水、酸性KMnO₄褪色

碳碳三键：使溴水、酸性KMnO₄褪色，与Ag(NH₃)₂⁺反应

苯环：取代反应（卤代、硝化、磺化）

卤素原子：NaOH水溶液水解，NaOH醇溶液消去

羟基(-OH)：

醇羟基：与Na反应，酯化，氧化

酚羟基：弱酸性，与FeCl₃显色，与浓溴水反应

醛基(-CHO)：银镜反应，与新制Cu(OH)₂反应，还原为醇

羧基(-COOH)：酸性，酯化

酯基(-COO-)：水解

6.2 有机合成路线设计
增长碳链：炔钠与卤代烃反应，格氏试剂

缩短碳链：烯烃氧化，脱羧反应

官能团引入：

引入卤素：烷烃取代，烯烃加成

引入羟基：烯烃加水，卤代烃水解，醛酮还原

引入醛基：醇氧化，炔烃水合

引入羧基：醛氧化，酯水解

引入碳碳双键：醇消去，卤代烃消去

官能团保护：如醛基易氧化，可先转化为缩醛保护

五、化学实验
1. 常用仪器与基本操作
1.1 加热仪器
酒精灯：外焰温度最高，用火柴点燃，用灯帽盖灭

酒精喷灯：高温加热

水浴加热：温度不超过100℃

油浴、沙浴：更高温度加热

1.2 计量仪器
托盘天平：精确到0.1g，左物右码

量筒：粗略量取液体体积，不能加热，不能作反应容器

容量瓶：配制准确浓度溶液，检漏，不能长期储存溶液

滴定管：酸式（装酸性、氧化性溶液），碱式（装碱性溶液）

移液管：准确移取一定体积液体

1.3 分离提纯仪器
漏斗：普通漏斗、长颈漏斗、分液漏斗

蒸馏烧瓶：蒸馏、分馏

冷凝管：直形、球形、蛇形

蒸发皿：蒸发结晶

干燥管：干燥气体

1.4 基本操作
药品取用：

固体：粉末用药匙，块状用镊子

液体：倾倒法、滴加法

加热：先预热，后集中加热

溶解：固体研碎，搅拌，加热促进溶解

过滤："一贴二低三靠"

蒸发：搅拌，大量晶体析出时停止加热

蒸馏：加沸石，温度计水银球在支管口处

萃取分液：检漏，充分振荡，静置分层

洗涤沉淀：向过滤器中加水浸没沉淀，待水流尽，重复2-3次

2. 常见气体制备
2.1 氧气(O₂)
氯酸钾分解：2KClO₃ → 2KCl + 3O₂↑（MnO₂催化）

高锰酸钾分解：2KMnO₄ → K₂MnO₄ + MnO₂ + O₂↑

过氧化氢分解：2H₂O₂ → 2H₂O + O₂↑（MnO₂催化）

收集方法：排水法或向上排空气法

检验：带火星木条复燃

2.2 氢气(H₂)
锌与稀硫酸：Zn + H₂SO₄ → ZnSO₄ + H₂↑

收集方法：排水法或向下排空气法

检验：点燃，淡蓝色火焰，干冷烧杯壁有水珠

2.3 氯气(Cl₂)
二氧化锰与浓盐酸：MnO₂ + 4HCl(浓) → MnCl₂ + Cl₂↑ + 2H₂O（加热）

收集方法：向上排空气法或排饱和食盐水法

尾气处理：用NaOH溶液吸收

检验：湿润淀粉-KI试纸变蓝

2.4 二氧化碳(CO₂)
大理石与稀盐酸：CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑

收集方法：向上排空气法

检验：通入澄清石灰水变浑浊

2.5 氨气(NH₃)
铵盐与碱：2NH₄Cl + Ca(OH)₂ → CaCl₂ + 2H₂O + 2NH₃↑（加热）

收集方法：向下排空气法

检验：湿润红色石蕊试纸变蓝；遇浓HCl产生白烟

2.6 二氧化硫(SO₂)
亚硫酸盐与酸：Na₂SO₃ + H₂SO₄ → Na₂SO₄ + H₂O + SO₂↑

收集方法：向上排空气法

尾气处理：用NaOH溶液吸收

检验：使品红溶液褪色，加热恢复红色

3. 物质检验
3.1 常见离子检验
H⁺：紫色石蕊试液变红；pH试纸变红；加Zn有气泡

OH⁻：红色石蕊试液变蓝；pH试纸变蓝；加酚酞变红

Cl⁻：加AgNO₃和稀HNO₃，白色沉淀

Br⁻：加AgNO₃和稀HNO₃，淡黄色沉淀

I⁻：加AgNO₃和稀HNO₃，黄色沉淀；加氯水和淀粉变蓝

SO₄²⁻：加BaCl₂和稀HCl，白色沉淀

CO₃²⁻：加酸产生使石灰水变浑浊的气体

NH₄⁺：加NaOH加热，产生使湿润红色石蕊试纸变蓝的气体

Fe²⁺：加KSCN无现象，再加氯水变红；加NaOH，白色沉淀→灰绿→红褐

Fe³⁺：加KSCN变红；加NaOH，红褐色沉淀

Al³⁺：加NaOH，白色沉淀，过量NaOH沉淀溶解

Cu²⁺：蓝色溶液；加NaOH，蓝色沉淀

3.2 常见气体检验
O₂：带火星木条复燃

H₂：点燃，淡蓝色火焰，干冷烧杯壁有水珠

Cl₂：黄绿色，使湿润淀粉-KI试纸变蓝

CO₂：使澄清石灰水变浑浊

SO₂：使品红褪色，加热恢复

NH₃：使湿润红色石蕊试纸变蓝；遇浓HCl产生白烟

NO：无色，遇空气变红棕色

NO₂：红棕色，溶于水生成无色NO和HNO₃

HCl：使湿润蓝色石蕊试纸变红；遇NH₃产生白烟

4. 定量实验
4.1 中和滴定
原理：n(H⁺) = n(OH⁻)

仪器：酸式滴定管、碱式滴定管、锥形瓶、铁架台

指示剂选择：

强酸强碱滴定：酚酞或甲基橙

强酸弱碱：甲基橙

强碱弱酸：酚酞

操作步骤：洗涤→润洗→装液→排气泡→调零→滴定→读数

误差分析：根据c(标)×V(标) = c(待)×V(待)判断

4.2 硫酸铜晶体结晶水测定
原理：CuSO₄·xH₂O → CuSO₄ + xH₂O

步骤：称量坩埚→加样品→加热至白色→冷却称量→再加热至恒重

计算：x = (m(样品)-m(无水物))/18 ÷ (m(无水物)/160)

4.3 中和热的测定
仪器：保温杯、温度计、环形玻璃搅拌棒

计算：ΔH = -[cmΔT]/n(H₂O)

六、化学计算
1. 物质的量计算
1.1 基本公式
n = N/N_A

n = m/M

n = V/V_m（气体，标准状况）

n = cV（溶液）

1.2 溶液配制与稀释
配制一定物质的量浓度溶液：

计算→称量→溶解→转移→洗涤→定容→摇匀

稀释公式：c₁V₁ = c₂V₂

混合溶液浓度计算：c = (c₁V₁ + c₂V₂)/(V₁ + V₂)（近似）

1.3 气体定律应用
同温同压：V₁/V₂ = n₁/n₂

同温同容：p₁/p₂ = n₁/n₂

阿伏伽德罗定律推论：

同温同压：ρ₁/ρ₂ = M₁/M₂

同温同压同体积：m₁/m₂ = M₁/M₂

2. 化学方程式计算
2.1 基本步骤
写出配平的化学方程式

列出已知量和未知量

列出比例关系

计算求解

检查答案合理性

2.2 常用方法
关系式法：多步反应，找最初反应物与最终产物关系

差量法：根据质量差、体积差、物质的量差计算

十字交叉法：混合气体平均分子量、溶液混合等

守恒法：

质量守恒：反应前后质量不变

原子守恒：反应前后各原子数目不变

电荷守恒：溶液中阳离子正电荷总数=阴离子负电荷总数

电子守恒：氧化还原反应中得失电子数相等

极值法：判断混合物组成范围

平均值法：根据平均分子量、平均组成推断

3. 溶液计算
3.1 溶解度计算
溶解度(S) = (溶质质量/溶剂质量) × 100g

饱和溶液：S/(100+S) = 溶质质量/溶液质量

结晶计算：温度变化或溶剂减少引起的晶体析出

3.2 溶液浓度换算
物质的量浓度(c)与质量分数(w)：

c = 1000ρw/M（ρ：g/cm³，M：g/mol）

饱和溶液溶解度(S)与质量分数(w)：

w = S/(100+S) × 100%

3.3 pH计算
强酸：pH = -lgc(H⁺)

强碱：pOH = -lgc(OH⁻)，pH = 14-pOH

混合溶液：

强酸混合：c(H⁺)混合 = [c(H⁺)₁V₁ + c(H⁺)₂V₂]/(V₁+V₂)

强碱混合：c(OH⁻)混合 = [c(OH⁻)₁V₁ + c(OH⁻)₂V₂]/(V₁+V₂)

酸碱混合：先判断过量，再计算

复合材料：玻璃钢、碳纤维复合材料

2. 化学与能源
化石燃料：煤、石油、天然气

煤：干馏（炼焦）、气化、液化

石油：分馏、裂化、裂解、催化重整

天然气：主要成分甲烷

新能源：氢能、太阳能、生物质能、核能

电池：一次电池（干电池）、二次电池（铅蓄电池、锂电池）、燃料电池

3. 化学与环境
大气污染：

酸雨：SO₂、NO_x引起，pH<5.6

光化学烟雾：NO_x、碳氢化合物引起

臭氧层破坏：氟氯烃（CFCs）引起

温室效应：CO₂、CH₄等引起

水污染：重金属离子、有机物、营养物质（富营养化）

土壤污染：重金属、农药、化肥

固体废物：白色污染（塑料）、工业废渣
