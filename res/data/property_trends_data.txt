原子半径|
=== 原子半径递变规律 ===\n\n一、同周期元素（从左到右）：\n  1. 原子半径逐渐减小\n  2. 原因：核电荷数增加，电子层数相同，原子核对电子的吸引力增强\n  3. 减小的幅度逐渐变小\n\n二、同主族元素（从上到下）：\n  1. 原子半径逐渐增大\n  2. 原因：电子层数增加，外层电子离核更远\n  3. 增大的幅度比同周期变化更明显\n\n三、典型变化序列：\n  1. 第三周期：Na(186pm) > Mg(160) > Al(143) > Si(117) > P(110) > S(104) > Cl(99)\n  2. 碱金属族：Li(152) < Na(186) < K(227) < Rb(248) < Cs(265)\n  3. 卤素族：F(71) < Cl(99) < Br(114) < I(133)\n\n四、特殊规律：\n  1. 镧系收缩：镧系元素原子半径减小不明显（仅减小11pm）\n  2. 过渡元素：同周期变化不大，半径相近\n  3. 稀有气体：原子半径较大（范德华半径）\n\n五、影响因素：\n  1. 核电荷数：正相关\n  2. 电子层数：正相关\n  3. 电子间斥力：负相关\n\n六、记忆技巧：\n  "同周右走半径小，核吸电子力增强；\n   同族下行半径大，电子层层往外跑；\n   过渡变化很平缓，镧系收缩要知道。"|

电负性|
=== 电负性递变规律 ===\n\n一、鲍林电负性标度：\n  1. 范围：0.7（Cs）到 4.0（F）\n  2. 非金属元素一般大于2.0\n  3. 金属元素一般小于1.5\n\n二、同周期元素（从左到右）：\n  1. 电负性逐渐增大\n  2. 非金属性增强，金属性减弱\n  3. 稀有气体电负性为0（不形成普通化合物）\n\n三、同主族元素（从上到下）：\n  1. 电负性逐渐减小\n  2. 金属性增强，非金属性减弱\n  3. 但第2周期元素有例外（N、O、F电负性特别大）\n\n四、典型电负性值：\n  1. F: 4.0（最大）     O: 3.5     N: 3.0     Cl: 3.0\n  2. C: 2.5     H: 2.1     Si: 1.8\n  3. Na: 0.9    K: 0.8     Cs: 0.7（最小）\n\n五、电负性差值与应用：\n  1. 差值 > 1.7：离子键为主\n  2. 差值 0.4-1.7：极性共价键\n  3. 差值 < 0.4：非极性共价键\n  4. 判断元素氧化态\n  5. 预测化合物酸碱性\n\n六、记忆口诀：\n  "右上氟氯氧氮强，电负最大四氟王；\n   左下铯铷钾钠弱，金属活泼电负小；\n   同周右走电负增，同族下行电负降。"|

电离能|
=== 电离能递变规律 ===\n\n一、定义与分类：\n  1. 第一电离能：气态原子失去一个电子所需能量\n  2. 第二电离能：气态+1价离子再失去一个电子所需能量\n  3. 单位：kJ/mol 或 eV\n\n二、同周期元素（从左到右）：\n  1. 总体趋势增大\n  2. 但有波动：Be > B，N > O（半满、全满结构稳定）\n  3. 稀有气体电离能最大\n\n三、同主族元素（从上到下）：\n  1. 逐渐减小\n  2. 原子半径增大，核对外层电子吸引力减弱\n  3. 碱金属电离能最小\n\n四、典型第一电离能（kJ/mol）：\n  1. He: 2372（最大）     Ne: 2081     Ar: 1520\n  2. F: 1681     O: 1314     N: 1402\n  3. Li: 520     Na: 496     K: 419     Cs: 376（碱金属中最小）\n  4. H: 1312\n\n五、电离能突变点：\n  1. 从ⅡA到ⅢA族：下降（Be 899 → B 801）\n  2. 从ⅤA到ⅥA族：下降（N 1402 → O 1314）\n  3. 半满（p³,d⁵,f⁷）和全满（p⁶,d¹⁰,f¹⁴）结构稳定\n\n六、影响因素：\n  1. 核电荷数：正相关\n  2. 原子半径：负相关\n  3. 电子构型：半满全满时电离能较大\n  4. 电子屏蔽效应\n\n七、应用：\n  1. 判断元素金属性强弱\n  2. 解释元素化合价\n  3. 预测化学反应活性|

电子亲和能|
=== 电子亲和能递变规律 ===\n\n一、定义与意义：\n  1. 气态原子获得一个电子释放的能量\n  2. 正值表示释放能量（放热），负值表示吸收能量（吸热）\n  3. 反映原子获得电子的能力\n\n二、同周期元素（从左到右）：\n  1. 绝对值总体增大（放热更多）\n  2. 卤素最大，容易得到电子\n  3. 碱土金属和稀有气体很小或为正值（难得到电子）\n\n三、同主族元素（从上到下）：\n  1. 绝对值总体减小\n  2. 但Cl(-349) > F(-328)（F原子太小，电子云密度大，排斥力强）\n  3. O(-141) < S(-200)（类似原因）\n\n四、常见元素电子亲和能（kJ/mol）：\n  1. Cl: -349（卤素中最大）     F: -328\n  2. Br: -324     I: -295\n  3. O: -141     S: -200\n  4. C: -122     Si: -134\n  5. H: -73\n  6. Li: -60     Na: -53     K: -48\n\n五、第二电子亲和能：\n  1. 总是正值（吸收能量）\n  2. O获得第一个电子：-141 kJ/mol\n  3. O⁻获得第二个电子：+744 kJ/mol\n\n六、影响因素：\n  1. 原子半径：半径小，亲和能大（但F、O例外）\n  2. 核电荷数：电荷多，亲和能大\n  3. 电子构型：稳定构型（全满、半满）亲和能小\n  4. 电子间排斥力\n\n七、记忆要点：\n  "氯的亲和能最大，氟氧反常要记牢；\n   同周右走亲和增，同族下行亲和小；\n   二亲总是正值多，得电子难要知晓。"|

金属性/非金属性|
=== 金属性与非金属性递变规律 ===\n\n一、判断标准：\n  1. 金属性：易失电子，还原性强，碱性氢氧化物\n  2. 非金属性：易得电子，氧化性强，酸性氢化物\n\n二、周期表中位置关系：\n  1. 左下角：金属性最强（Cs, Fr）\n  2. 右上角：非金属性最强（F, O, N）\n  3. 对角线区域：类金属（B, Si, Ge, As, Sb, Te, Po）\n\n三、同周期（从左到右）：\n  1. 金属性减弱，非金属性增强\n  2. 变化序列：强金属 → 弱金属 → 两性 → 类金属 → 弱非金属 → 强非金属\n  3. 第三周期：Na(强金属) > Mg > Al(两性) > Si(类金属) > P(弱非金属) > S > Cl(强非金属)\n\n四、同主族（从上到下）：\n  1. 金属性增强，非金属性减弱\n  2. 第ⅣA族：C(非金属) → Si(类金属) → Ge(类金属) → Sn(金属) → Pb(金属)\n  3. 第ⅤA族：N(非金属) → P(非金属) → As(类金属) → Sb(类金属) → Bi(金属)\n\n五、金属性强弱比较：\n  1. 与水反应：K剧烈，Na较快，Mg慢，Al不反应\n  2. 与酸反应：Zn快，Fe中，Cu不反应\n  3. 最高价氧化物水化物碱性：NaOH强碱，Mg(OH)₂中强碱，Al(OH)₃两性\n\n六、非金属性强弱比较：\n  1. 与H₂反应：F₂冷暗爆炸，Cl₂光照爆炸，Br₂加热，I₂高温可逆\n  2. 氢化物稳定性：HF最稳定，HCl次之，HBr、HI不稳定\n  3. 最高价含氧酸酸性：HClO₄最强酸，H₂SO₄强酸，H₃PO₄中强酸\n\n七、应用：\n  1. 预测元素化学性质\n  2. 判断化合物酸碱性\n  3. 解释置换反应规律\n  4. 指导金属冶炼方法|

熔点沸点|
=== 熔点和沸点递变规律 ===\n\n一、同周期元素单质：\n  1. 从左到右，熔沸点先升高后降低\n  2. 最高点在IVA族（C, Si）或过渡金属中部\n  3. 金属：Na < Mg < Al（金属键增强）\n  4. 非金属：Si > P > S > Cl（分子晶体分子量减小）\n\n二、同主族元素单质：\n  1. 金属：从上到下熔沸点降低（碱金属、碱土金属）\n  2. 非金属：从上到下熔沸点升高（卤素、氧族）\n  3. 碳族：C（金刚石）> Si > Ge > Sn > Pb（金属键出现）\n\n三、典型元素熔沸点（℃）：\n  1. 最高熔点：C（金刚石）3550，W 3422，Re 3186\n  2. 最低熔点：Hg -38.83（常温液态金属）\n  3. 最高沸点：C（石墨）4827，W 5660\n  4. 最低沸点：He -268.93，H₂ -252.87\n  5. 金属单质：Na 97.8，Fe 1538，Cu 1084\n  6. 非金属单质：S 115，P 44，I 113.7（升华）\n\n四、晶体类型影响：\n  1. 原子晶体：熔沸点最高（金刚石、SiC、SiO₂）\n  2. 金属晶体：较高，与金属键强度有关\n  3. 离子晶体：较高（NaCl 801℃，MgO 2852℃）\n  4. 分子晶体：较低，与分子间作用力有关\n\n五、特殊现象：\n  1. 碳的多种同素异形体：金刚石 > 石墨 > 富勒烯\n  2. 白磷（44℃）和红磷（590℃）熔点不同\n  3. 锡的"锡疫"：白锡（232℃）→灰锡（<13.2℃）\n\n六、影响因素：\n  1. 化学键强度：共价键 > 离子键 > 金属键 > 分子间力\n  2. 分子量：分子晶体中分子量大者熔沸点高\n  3. 分子极性：极性分子熔沸点较高\n  4. 氢键：大幅提高熔沸点（H₂O、HF、NH₃）|

密度|
=== 密度递变规律 ===\n\n一、同周期元素单质：\n  1. 从左到右密度总体增大\n  2. 碱金属、碱土金属密度较小\n  3. 过渡金属密度较大\n  4. 卤素、稀有气体密度很小（气态或低密度固态）\n\n二、同主族元素单质：\n  1. 从上到下密度增大\n  2. 原子量增加的影响大于原子体积增加\n  3. 但碱金属有波动：Li 0.534 < Na 0.968 > K 0.856 < Rb 1.532 < Cs 1.879\n\n三、密度排行榜：\n  1. 最大元素（g/cm³）：\n     • Os 锇：22.59\n     • Ir 铱：22.56\n     • Pt 铂：21.45\n     • Re 铼：21.02\n     • Au 金：19.32\n  2. 最小元素：\n     • H₂ 氢气：0.0899 g/L（气态，标准状况）\n     • Li 锂：0.534（最轻金属）\n     • Na 钠：0.968\n     • K 钾：0.856\n\n四、典型密度序列：\n  1. 碱金属：Li(0.534) < Na(0.968) < K(0.856) < Rb(1.532) < Cs(1.879) < Fr(估计1.87)\n  2. 卤素（固态）：F(1.696) < Cl(1.56) < Br(3.12) < I(4.93)\n  3. 第四周期：K(0.856) < Ca(1.55) < Sc(2.99) < Ti(4.54) < V(6.11) < Cr(7.19) < Mn(7.43) < Fe(7.87)\n\n五、密度与性质关系：\n  1. 密度大的金属通常：硬度大、熔点高、耐腐蚀\n  2. 密度小的金属通常：活泼、质地软、低熔点\n  3. 贵金属（Au、Pt、Ag）密度都较大\n\n六、特殊现象：\n  1. 钾密度小于钠：原子量增加但原子半径增加更多\n  2. 汞是液态金属：密度13.534 g/cm³\n  3. 锇是最密金属：用于制造高密度合金\n\n七、应用：\n  1. 合金设计：调整密度满足特定需求\n  2. 材料选择：航空航天用轻金属，配重用重金属\n  3. 分离提纯：利用密度差异进行分离|

综合规律总结|
=== 元素性质递变综合规律总结 ===\n\n一、周期性变化总表：\n  性质          同周期（左→右）    同主族（上→下）\n  ──────────────────────────────────────\n  原子半径        减小               增大\n  电离能          增大               减小\n  电负性          增大               减小\n  金属性          减弱               增强\n  非金属性        增强               减弱\n  电子亲和能      增大（绝对值）      减小（绝对值）\n  熔沸点          先增后减            金属减、非金属增\n  密度            增大               增大\n\n二、对角线规则（相似性规律）：\n  1. Li - Mg：性质相似\n     • 单质与氧反应都生成普通氧化物（Li₂O，MgO）\n     • 氢氧化物都是中强碱\n     • 碳酸盐受热分解\n  2. Be - Al：性质相似\n     • 两性元素，氢氧化物两性\n     • 被浓硝酸钝化\n     • 氧化物高熔点\n  3. B - Si：性质相似\n     • 类金属，半导体性质\n     • 氧化物酸性\n     • 形成多酸\n\n三、镧系收缩效应：\n  1. 现象：镧系元素原子半径仅减小11pm\n  2. 后果：\n     • 第5、6周期同族元素半径相近\n     • Zr(160pm) 与 Hf(159pm) 性质极相似\n     • Nb(146) 与 Ta(146)，Mo(139) 与 W(139)\n  3. 应用：锆铪、铌钽分离困难\n\n四、过渡元素特点：\n  1. 性质变化平缓\n  2. 多种氧化态（Mn：+2,+3,+4,+6,+7）\n  3. 化合物多有颜色（Cu²⁺蓝，Fe²⁺浅绿，Fe³⁺黄褐）\n  4. 易形成配合物\n  5. 催化性能好\n\n五、记忆口诀大全：\n  1. 原子半径：\n     "同周右走半径小，核吸电子力增强；\n      同族下行半径大，电子层层往外跑。"\n  \n  2. 电负性：\n     "右上氟氯氧氮强，电负最大四氟王；\n      左下铯铷钾钠弱，金属活泼电负小。"\n  \n  3. 金属性：\n     "左下金属右上非，对角相似要记牢；\n      同周右走金变弱，同族下行金增强。"\n  \n  4. 综合规律：\n     "七横七周期，族竖十六立；\n      左上到右下，性质渐变异。\n      金属左下角，非金右上区；\n      过渡中间站，变化很平易。\n      对角有相似，镧系收缩奇；\n      周期规律妙，化学真神奇！"\n\n六、周期律应用：\n  1. 预测新元素性质\n  2. 寻找替代材料\n  3. 解释化学反应规律\n  4. 指导合成新化合物\n  5. 理解生物体内元素功能\n\n七、学习建议：\n  1. 结合周期表位置记忆\n  2. 理解物理本质原因\n  3. 多做比较和归纳\n  4. 联系实际应用\n  5. 掌握例外和特殊情况|
