# 元素周期表软件 v1.3.5 Beta

## 📖 软件简介

这是一个功能全面的化学元素周期表桌面应用程序，专为化学学习、教学和研究设计。软件提供了丰富的化学工具、可视化功能和交互式学习体验。

## 🛠️ 开发信息

开发语言: Python 3
图形界面: Tkinter
策划: Sou Amezawa
开发: Sive-Nioo Studios
版本: 1.3.5 Beta
发布日期: 2026年9月

## 📱 系统要求

* 操作系统: 最好Windows10/11
* Python: 3.11 或更高版本
* 内存: 至少 512MB RAM
* 磁盘空间: 至少 50MB 可用空间

## 🔧 安装和使用

1. 首次使用：

   * 运行程序后会自动显示激活界面
   * 输入正确的激活密钥完成激活
   * 激活成功后即可正常使用
2. 基本操作：

   * 点击周期表中的元素查看详细信息
   * 使用顶部菜单访问各种功能
   * 在搜索框中输入元素符号、名称或原子序数快速定位
3. 数据更新：

   * 修改 res/data/ 目录下的对应txt文件即可更新数据
   * 数据格式请参考现有文件的结构

## 🎮 学习游戏说明

1. 元素记忆游戏：

   * 匹配元素符号和名称
   * 每对匹配获得10分，错误扣2分
2. 化学式拼写练习：

   * 根据化合物名称写出化学式
   * 正确+5分，连续正确有额外奖励
3. 反应配平练习：

   * 配平化学方程式
   * 正确配平获得10分
4. 化学知识测验：

   * 选择题形式测试化学知识
   * 每道题5分
